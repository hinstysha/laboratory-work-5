## Описание

Выполнение лабораторной работы № 5 «Визуальное программирование на Python».

Цель — научиться создавать графические интерфейсы с использованием Tkinter: окна, кнопки, поля ввода, вкладки, диалоги и встроенные графики.

Вариант 1: средняя сложность — задания **1, 3, 5**; повышенная сложность — задания **1, 4**.

Каждое задание находится в отдельном модуле с функцией `main()` и защитой `if __name__ == "__main__"`. При импорте окна не создаются. Обработчики событий отделены от запуска приложения; арифметика и вычисление точек графика вынесены в функции.

## Требования и проверка стиля

- Python 3.9 или выше с поддержкой Tkinter.
- Графическая среда: приложения открывают окна и не предназначены для запуска в терминале без дисплея.

Проверьте Tkinter:

```bash
python -m tkinter
```

Должно открыться демонстрационное окно. В стандартном установщике Python для Windows компонент Tcl/Tk обычно доступен. Если модуль отсутствует, добавьте компонент Tcl/Tk через установщик Python. В Linux пакет Tkinter устанавливается системным пакетным менеджером для используемого Python. Команда `pip install tkinter` не является способом его установки.

Для проверки стиля установите flake8:

```bash
python -m pip install flake8==7.3.0
python -m flake8 .
```

Подключите Git-хук из папки репозитория:

```bash
git config core.hooksPath hooks
chmod +x hooks/pre-commit
```

В Windows эти команды выполняются в Git Bash. Хук проверяет все Python-файлы рабочей папки и отменяет коммит при ошибках flake8.

## Выполненные задания

### Средн.1 — задание 1: окно с кнопкой «Привет»

Файл `hello_button.py`. Главное окно содержит надпись и кнопку `ttk.Button`. Параметр `command` связывает кнопку с функцией `show_greeting()`. При нажатии появляется диалог `messagebox.showinfo()` с приветствием.

```bash
python hello_button.py
```

Проверка: нажмите «Привет», закройте сообщение и главное окно.

### Средн.2 — задание 3: простейший калькулятор

Файл `calculator.py`. Класс `CalculatorApp` создаёт два поля ввода, список операций `+`, `-`, `*`, `/`, кнопку и область результата.

Функция `calculate()` выполняет арифметику независимо от интерфейса. Обработчик `show_result()` преобразует ввод в числа и отображает результат. Разрешены точка и запятая как десятичный разделитель. Пустой и нечисловой ввод, неконечные числа, деление на ноль и переполнение обрабатываются сообщениями об ошибке. `eval()` не используется.

```bash
python calculator.py
```

Проверка: `12 + 3 = 15`, `12 - 3 = 9`, `12 * 3 = 36`, `12 / 3 = 4`. Попробуйте также `1,5 + 2,5`, деление на ноль и ввод букв. Результат отображается с точностью до 12 значащих цифр; вычисления выполняются с `float`.

### Средн.3 — задание 5: программа со вкладками Notebook

Файл `notebook_tabs.py`. Класс `TabsApp` создаёт `ttk.Notebook` с тремя вкладками: «Описание», «Ввод» и «Результат». Каждая вкладка — отдельный контейнер `ttk.Frame`.

На вкладке «Ввод» пользователь указывает имя. Кнопка формирует приветствие и переключает интерфейс на «Результат» через `Notebook.select()`. Для пустого имени выводится подсказка.

```bash
python notebook_tabs.py
```

Проверка: переключитесь между вкладками, введите имя и нажмите «Показать приветствие».
